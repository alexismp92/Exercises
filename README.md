# Exercises
This repository contains some common exercises on interviews. I created it in order to share and help other software engineers to prepare for interviews with the solutions.

## CART
Implementation of a shopping cart

## PALINDROME
Requires to evaluate if a given word is a palindrome or not.  Example of palindrome words: "level", "radar", "civic", "madam", "refer".

## STACK
This is a simple stack (Fist In Last Out) structure created with java.

## MODE
Given a list of numbers, find the mode of the elements. The mode is the number that appears most frequently in the list.
If there are multiple modes, return the minimum value of the mode.

## STORE SHIPMENT
Some stores operate a BPS (Bulk Product Shipment) system that manually matches requisition orders with available pooling agents based on priority and availability.
You’ve been asked to design a system to simulate the manual pooling process, where requisitions are batched and assigned to available stores/agents based on matching criteria.
